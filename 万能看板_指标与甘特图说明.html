1. 核心规则：只扣外部验证独占时段

在对应统计范围内，先合并内部任务区间 I、外部验证区间 E。需扣区间 D＝E − I，即有外部验证、但没有内部任务覆盖的部分。这是时间区间的集合差，不能简单用两个总时长相减。

Case 对照全案内部任务；部门只对照本部门及下级内部任务。外部任务归属内部对接负责人所在部门。自动按时间计算，不需要额外操作“暂停 Case”。

指标计算方式
Case 总 Cycle Time实际结案时间 − 创建时间；未结案取统一统计时点。
Case 有效 Cycle TimeCase 总 Cycle Time − 全案外部独占区间 D 的时长。
本部门总 Cycle Time同一 Case 内，本部门及下级全部任务（含外部验证）的时间区间合并去重。
本部门有效 Cycle Time本部门总 Cycle Time − 本部门及下级范围内外部独占区间 D 的时长。
单个任务 Cycle Time任务结束时间 − 创建时间；未结束取当前。内部、外部任务分别计时，不因其他任务而暂停。
任务平均 Cycle Time内部任务 Cycle Time 之和 ÷ 有效计时的内部任务数。外部验证不进入分子或分母。
外部验证时长每项外部验证任务独立计算完整任务时长；不等于最终需要扣除的时长。

3. 平均值与本例结果

部门平均：先分别计算每个 Case 的本部门周期，再平均。例如 6 天、10 天，平均为 8 天。不同 Case 不跨案合并；父部门重新合并下级任务区间，不直接相加下级结果。

任务平均：内部 A、B、C 为 7、4、2 天，平均（7＋4＋2）÷3＝4.33 天，不扣任务间并行重叠。外部 D、E、F、G 共 6 天，不参与平均；其中独占 3 天，重合的另 3 天保留。

4. 数量、筛选与边界

  • Case 数：按所选人员身份匹配本部门及下级，按 Case ID 去重。
  • 普通任务数：包含内部任务与独立外部验证任务；任务平均的分母只包含有效计时的内部任务。
  • 仅有 Owner／创建人／协作者关系、没有本部门任务：可计入 Case 数，部门周期显示“—”，不按 0 参与平均。
  • 有外部任务但没有内部任务：部门总值有值，有效值为 0，内部任务平均为“—”。
  • 任务完成、拒绝或中止后停止计时；未结束取统一统计时点。Case 内任务统计区间限制在 Case 生命周期内，缺失或无效时间不当作 0。
  • 旧内部验证仅保留历史，不再扣时；未明确类型的旧记录不自动视为外部验证。
